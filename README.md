# ML Coursework 2025

Machine Learning coursework project.

## Project Structure

This coursework is organized into four main sections:

### 1. Regression (`regression_uc23526/`)
- `task1.py` - Linear regression
- `task2.py` - Neural network
- `task3.py` - Bayesian regression
- `report_regression.pdf` - Regression report

### 2. Classification (`classification_uc23526/`)
- `task4.py` - Dimensionality reduction
- `task5.py` - Decision tree classifier
- `task6.py` - Ensemble classifier
- `task7.py` - SVM classifier
- `report_classification.pdf` - Classification report

### 3. Clustering (`clustering_uc23526/`)
- `clustering.ipynb` - Clustering notebook
- `report_clustering.pdf` - Clustering report

### 4. Sequential Data (`seq_uc23526/`)
- `hmms.py` - Hidden Markov Models
- `report_seq.pdf` - Sequential data report

## Submission

When ready to submit, create a zip file named `cw_uc23526.zip` containing all four folders.
