# Classification Section

## Dataset

Download CIFAR-10 dataset:
```bash
wget https://www.cs.toronto.edu/~kriz/cifar-10-python.tar.gz
tar -xvzf cifar-10-python.tar.gz
```

The extracted `cifar-10-batches-py/` folder should be in this directory.

## Files

- `task4.py` - Dimensionality reduction code task
- `task5.py` - Decision tree classifier code task
- `task6.py` - Ensemble classifier code task
- `task7.py` - SVM classifier code task
- `report_classification.pdf` - Classification report (convert to PDF for submission)
